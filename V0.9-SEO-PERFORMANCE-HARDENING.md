# V0.9 — SEO + Performance Hardening

## Release status

V0.9 hardens the GEI-ERA public site for search discovery, social sharing, accessibility, mobile delivery, and portable deployment.

## Delivered

- XML sitemap at `/sitemap.xml` covering currently published public routes.
- `robots.txt` with a sitemap declaration.
- Lightweight `site.webmanifest` for installable/mobile metadata.
- Dedicated `404.html` fallback with `noindex` handling.
- Existing public pages retain canonical URLs and human-readable metadata.
- Structured-data layer is prepared for Organization/WebSite/WebPage/CollectionPage markup without making unsupported scholarly claims.
- SEO language is human-oriented; no keyword stuffing.
- Performance direction: keep the site dependency-light, avoid unnecessary runtime libraries, preserve reduced-motion support, and prefer local/static assets.

## Important limitation

This release does not claim a measured Core Web Vitals score, Search Console status, or PageSpeed score. Those require deployment-level testing against the live Hostinger/Vercel environment.

## Integrity rule

SEO metadata must describe what the page actually contains. Structured data must not be used to imply that GEI interpretations are established historical or scientific facts.
