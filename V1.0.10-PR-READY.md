# V1.0.10 PR QA Checklist

## Command Center
- [ ] `/commands/` loads independently.
- [ ] `open research` routes to Research.
- [ ] `start dam lab` routes to Laboratory.
- [ ] `view my progress` routes to Progress.
- [ ] `show my journey` routes to Timeline.
- [ ] `explore day one` routes to Explore/Content.
- [ ] Unknown command does not navigate.
- [ ] Recent commands persist and clear.
- [ ] Ctrl+Shift+K / Cmd+Shift+K focuses the input.

## Search integration
- [ ] A recognized command entered in `/search/` executes through GEI_COMMANDS.
- [ ] A non-command search still uses the V1.0.9 result path.

## Timeline integration
- [ ] Executing a command creates a browser-local `command` activity event.
- [ ] Existing navigation/activity events remain functional.

## Platform integration
- [ ] Unified navigation recognizes `/commands/`.
- [ ] Integration status reports V1.0.10.
- [ ] Mobile navigation remains usable.

## Integrity
- [ ] No command claims authentication or authorization.
- [ ] No command verifies payment or entitlement.
- [ ] No command changes research evidence/claims/provenance.
- [ ] Browser-local command history is not represented as authoritative.
