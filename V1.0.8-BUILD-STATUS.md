# V1.0.8 Build Status

V1.0.8 adds the GEI Unified Activity Timeline & Journey Layer.

The timeline records local platform activity such as navigation, session/profile changes, discovery, knowledge graph interaction, progress, portfolio activity, and other supported module events.

This layer is presentation/activity history only. It is not an academic transcript, research record, identity system, payment history, credential, or server-backed audit log.
