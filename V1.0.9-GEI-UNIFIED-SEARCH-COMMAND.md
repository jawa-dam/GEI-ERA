# V1.0.9 — GEI Unified Search & Command Layer

## Purpose

V1.0.9 creates a single command/search surface for navigating the current GEI ecosystem. It builds on Discovery, Knowledge Graph, Timeline, and the existing Platform Registry.

## Implemented

- `/search/` unified search surface
- Versioned curated search dataset
- Relevance scoring across record IDs, titles, types, categories, and descriptions
- Category filtering
- Recent command history using browser-local storage
- Enter-to-open top result
- Ctrl+K / Cmd+K focus shortcut
- Search registration in the Platform Registry
- Unified navigation integration
- Responsive and reduced-motion support
- SEO metadata and canonical URL

## Search contract

The current index is intentionally curated. It is a navigation index, not a replacement for the authoritative data owned by Research, Commerce, Profile, Progress, or other systems. Future adapters can expand the index without changing the public search interface.

## Integrity boundary

A search result is not proof that a claim is true, historically established, scientifically validated, academically accepted, commercially purchased, identity-verified, or credentialed. Search only helps the visitor find an existing GEI surface.

Browser-local search history is convenience state and is not an authoritative record.

## Acceptance criteria

1. `/search/` loads independently.
2. Search returns relevant curated GEI records.
3. Category filters update results.
4. Opening a result reaches the intended existing system route.
5. Recent commands persist locally and can be cleared.
6. Ctrl+K / Cmd+K focuses the search field.
7. Mobile layout remains usable.
8. Search does not claim authoritative identity, payment, research, academic, or credential status.
9. V1.0.9 claims remain limited to implemented functionality.
