# V0.6 — GEI Commerce + Vault

## Purpose
V0.6 introduces the provider-neutral commerce and entitlement layer for Genesis Engineered Interpretations.

## Delivered
- Product catalog with stable product IDs and SKUs.
- GEI Discovery Guide — $10 USD.
- GEI Blueprint Collection — $25 USD.
- GEI Premium Blueprint Access — $69 USD.
- Provider-neutral checkout handoff event.
- Local entitlement state for development/demo use.
- Vault access model based on entitlements.
- Explicit separation between demo access and purchases.
- No payment credentials in client code.
- Responsive marketplace and Vault interface.
- SEO metadata and canonical URL.

## Security boundary
V0.6 is a front-end commerce architecture, not a payment processor. A real purchase must be verified by a trusted server/payment integration before an `active` entitlement is issued. Client-side local storage must never be treated as proof of payment.

## Integration contract
A future provider adapter may call `GEI_COMMERCE_ENGINE.recordProviderEntitlement()` after server-side verification. The content/product IDs remain provider-neutral.

## Definition of Done
- Product cards render.
- Prices are visible.
- Vault states are visible.
- Demo entitlement can be tested without implying a purchase.
- Checkout handoff is provider-neutral.
- Mobile layout is responsive.
- Accessibility basics and reduced-motion behavior are present.
- No payment secrets are shipped to the browser.
