# V1.0.12 Pull Request Review Guide

## Review objective
Verify that the provenance layer provides structured, inspectable browser-local traceability without becoming an authority over identity, payments, credentials, research evidence, or protected state.

## Required flow

1. Open `/provenance/`.
2. Navigate to Commands.
3. Execute `open research`.
4. Execute `start dam lab`.
5. Return to Provenance.
6. Inspect the command and module-action events.
7. Confirm actor, action, module, target, source, occurredAt, recordedAt, context, and integrity fields are present.
8. Clear the local trail and confirm it resets.
9. Test mobile layout.
10. Confirm no authoritative-audit language is presented.

## Expected integrity state

New local records use `verificationState: local-unverified` and `authoritative: false` unless a future trusted service supplies stronger evidence.
