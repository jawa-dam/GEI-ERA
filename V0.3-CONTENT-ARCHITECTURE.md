# V0.3 — GEI Content Architecture

**Project:** Genesis Engineered Interpretations (GEI)  
**Repository:** `jawa-dam/GEI-ERA`  
**Release:** V0.3  
**Focus:** Reusable Content Architecture

## Objective

Create a canonical content layer that can power the GEI website, Academy, Research repository, Library, Marketplace, Laboratory, and future Vault without hard-coding content into individual page layouts.

## Architecture

### Canonical record

Every content item follows `content/content-schema.json` and can carry:

- ID
- Title
- Slug
- Description
- Content type
- Category
- Author
- Created / updated dates
- Version
- Publication status
- Access level
- Price / currency
- Tags
- Sources
- Related content
- Media references
- SEO metadata
- Provenance / audit references

### Supported content types

- `research`
- `course`
- `lesson`
- `product`
- `book`
- `media`
- `guide`
- `dataset`

### Access model

The content layer distinguishes:

- `free`
- `premium`
- `unlocked`
- `member`

This is intentionally provider-neutral. Payment and entitlement systems remain outside the content record itself.

## V0.3 Content Explorer

`content/index.html` is the first working reference implementation.

It provides:

1. Search across title, description, category, author, tags, and sources.
2. Content-type filtering.
3. Record counts.
4. Reusable content cards.
5. Record detail inspection.
6. Access and pricing display.
7. Source and provenance visibility.
8. Persistent Dark / Light / System theme compatibility.
9. Responsive mobile layout.

## Seed Records

`content/content-data.js` contains representative GEI records covering research, lessons, guides, products, and media. These are architecture records and planned/public examples; the V0.3 interface does not activate commerce or claim that planned products are currently purchasable.

## Design Principle

The page is a renderer. The data record is the source of truth. Future GEI pages should consume the same record model rather than duplicating metadata in HTML.

## Next Evolution

V0.4 will consume this architecture for the GEI Academy. Later releases can add research repositories, products, entitlements, media, and structured detail pages without redesigning the underlying content model.
