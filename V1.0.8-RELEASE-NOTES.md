# V1.0.8 Release Notes — GEI Unified Activity Timeline & Journey Layer

V1.0.8 adds a chronological local journey view above the existing GEI Platform, Discovery, Knowledge Graph, Profile, Progress, and Portfolio foundations.

### Delivered

- `timeline/` module
- Timeline data contract
- Local activity engine
- Chronological rendering
- Navigation/session/discovery/knowledge/profile/progress/portfolio event hooks
- Clear-history control
- Responsive and reduced-motion presentation
- Explicit non-authoritative activity boundary

### Important

V1.0.8 does not create server analytics, authentication, payment verification, academic credit, or credential issuance. Browser-local activity remains convenience state.
