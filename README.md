# GEI-ERA

## Genesis Engineered Interpretations — Enterprise Research & Academy Platform

GEI-ERA is the canonical website foundation for Genesis Engineered Interpretations (GEI).

The repository is designed to evolve into a professional, SEO-ready digital platform combining:

- GEI Control Room dashboard
- GEI Academy
- GEI Research
- Interactive Laboratory
- GEI Library / Publishing
- Premium Vault / access control
- Marketplace and digital commerce
- Media experiences
- Branded merchandise
- Future membership and credential systems

## Current Release — V0.3

**V0.3 — Content Architecture** establishes the reusable knowledge layer underneath the GEI platform.

### V0.3 delivered

- Canonical GEI content-record JSON Schema.
- Reusable records for research, lessons, guides, products, and media.
- Stable IDs, slugs, versions, statuses, access levels, pricing, tags, sources, related records, media references, SEO metadata, and provenance fields.
- Provider-neutral free / premium / unlocked / member access model.
- Interactive GEI Content Explorer at `content/index.html`.
- Search across content metadata.
- Content-type filtering.
- Reusable content cards and record-detail inspection.
- Source and provenance visibility.
- Responsive mobile presentation.
- Dark / Light / System theme compatibility.
- Commerce remains separate from content data and is not activated by V0.3.

## V0.2 — Interactive Control Room

## Design Language

**Mountain → Water → Dam → Gates → Gears → Knowledge**

The site should feel like an interdisciplinary research institution and engineering laboratory while remaining approachable and commercially useful.

## Development Principle

Build in versioned stages. Each release should remain deployable, auditable, mobile-ready, and compatible with a future Hostinger production implementation.
