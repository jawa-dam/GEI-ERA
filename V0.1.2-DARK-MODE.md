# GEI-ERA V0.1.2 — Dark Mode

The GEI Control Room now supports a persistent Dark/Light appearance system.

- Dark mode remains the signature GEI experience.
- Light mode provides an academic reading environment.
- Theme preference persists in local storage.
- First visit follows the device preference.
- The theme control is keyboard accessible and mobile safe.
- The system is designed to be expanded later with system, dark, and light modes.
