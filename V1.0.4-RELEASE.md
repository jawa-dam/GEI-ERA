# V1.0.4 Release Summary

## GEI Unified Learning Progress & Achievement Layer

V1.0.4 introduces the first cross-system progress presentation layer for GEI. It consumes existing local session, profile, laboratory, and research state and presents a single progress view.

### Architecture

`Session → Profile → Progress → Achievements → Experience`

### Design rule

Derived local activity is never represented as proof of authentication, payment, verified identity, researcher status, or academic certification.

### Verification

Use `V1.0.4-TEST-PLAN.md` after GitHub Pages deploy. Do not mark V1.0.4 browser verification passed until the deployed `/progress/` experience has been tested.
