# V1.0.8 — GEI Unified Activity Timeline & Journey Layer

## Purpose

V1.0.8 introduces a chronological, browser-local journey surface for GEI activity. It gives the platform a human-readable history of navigation and selected module activity without treating local activity as an authoritative record.

## Implemented

- `/timeline/` activity journey surface
- Versioned timeline data layer
- Local activity engine with an 80-event presentation history
- Chronological event rendering with timestamps and module labels
- Clear-journey control
- Navigation activity capture through `gei-platform:navigate`
- Session, discovery, knowledge, profile, progress, and portfolio event hooks when those events are emitted
- Shared Platform Core, Session, Registry, and Unified Navigation support on the timeline surface
- SEO metadata, responsive layout, and reduced-motion support

## Activity model

Each timeline event contains:

- `id` — local event identifier
- `type` — activity category
- `title` — human-readable event title
- `module` — GEI module associated with the activity
- `detail` — contextual description
- `at` — local event timestamp represented as an ISO string

## Integrity boundary

The timeline is a presentation of browser-local activity. It is not:

- an authoritative academic transcript
- a server-backed audit log
- proof of research activity or authorship
- verified identity
- payment history or entitlement proof
- a credential or certification record

Future server-backed analytics can replace or augment the local layer without changing the presentation contract.

## Acceptance criteria

1. `/timeline/` loads independently.
2. Activity events render chronologically.
3. Navigation activity can be captured through the shared Platform Core event.
4. Existing module event hooks can contribute activity without requiring those modules to depend on the timeline UI.
5. Local history is bounded and resettable.
6. Mobile presentation remains usable.
7. Local activity is never represented as authoritative identity, payment, research, academic, or credential data.
8. V1.0.8 claims remain limited to implemented functionality.
